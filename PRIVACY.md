# Privacy Policy — MAGE AI Exporter

MAGE AI Exporter does not collect, store, or transmit any user data. All conversation processing occurs entirely within the user's browser.

The extension:

- Does NOT send data to any external server
- Does NOT use analytics or tracking
- Does NOT require user authentication
- Does NOT access conversations unless the user clicks Export
- Only activates on supported AI platform pages (claude.ai, chatgpt.com, gemini.google.com, grok.com, x.com/i/grok)

The extension requires the following permissions:
- **activeTab**: To read the current page's conversation content when you click Export
- **downloads**: To save the exported file to your computer
- **storage**: To remember your preferred export format between sessions
